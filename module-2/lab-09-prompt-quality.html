The course material describes prompt engineering as crafting specific prompts or instructions to guide an AI model toward relevant, accurate and high-quality responses. It is an iterative process.

INTERACT: Vague → Specific

Vague prompt

Tell me about cats.

The supplied module uses this as an example of a prompt that is vague, lacks focus and can lead to an unfocused answer.

More focused prompt

Write a fun short story about a cat who travels to the moon.

The task and desired direction are clearer.

What the analyzer looks for

  • Clear task/action
  • Specific topic or context
  • Audience/purpose

Why prompt engineering matters

Relevance

Well-crafted prompts help align responses with task objectives.

Accuracy

Specific context and requirements can improve the usefulness of responses, while outputs still need checking.

Versatility

Different prompt types can adapt outputs to many tasks.

Exam Corner

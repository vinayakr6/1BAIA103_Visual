🧱 1. Depth-Limited Search (DLS)

DLS is a depth-first search in which a fixed depth limit is imposed. A node at the limit is treated as if it were a leaf: its successors are not expanded. This prevents the search from continuing indefinitely down that branch. fileciteturn23file3

Without a limit

DFS can keep going deeper in an infinite or cyclic search space.

Risk: infinite loop

With a limit

Stop expansion when depth = L.

Control: cutoff

Important trade-off

If L is too small, the goal may be missed. If L is too large, unnecessary work increases. fileciteturn23file12

DLS mental model

DLS(node, limit)
  if node is goal → return solution
  if limit = 0 → return CUTOFF
  for each child of node
      result = DLS(child, limit - 1)
      if result is solution → return it
  return failure/cutoff

🔁 2. Iterative Deepening Depth-First Search (IDDFS)

IDDFS combines the depth-oriented behaviour of DFS with the progressive depth discovery of BFS. It starts with a small limit, performs a complete DLS, then increases the limit and starts again. It continues until the goal is found. fileciteturn23file0

Iteration 0

Search only depth 0.

Iteration 1

Search depths 0–1.

Iteration 2

Search depths 0–2.

Iteration 3

Search depths 0–3 → goal H.

Why it is useful: The VTU source highlights memory efficiency, completeness, and the combination of DFS depth efficiency with BFS-style progressive discovery. It gives time O(bd) and space O(b·d), where b is branching factor and d is goal depth. fileciteturn23file6

FeatureDLSIDDFS
Main ideaDFS with one fixed depth limit.Repeated DLS with increasing limits.
Depth limitChosen once.0, 1, 2, 3 … until solution.
MemoryDepth-first and memory efficient.Also memory efficient; source gives O(b·d).
RiskToo-small limit can miss a deeper goal.Repeats earlier work.

🏙️ Real-world intuition

Game solving

If the exact depth of a useful state is unknown, progressively deeper exploration can avoid committing to one arbitrary cutoff.

Route/state search

A system can explore shallow possibilities first while retaining DFS-like memory behaviour.

Large search spaces

IDDFS is particularly useful in the source material when the goal depth is not known.

These examples illustrate the algorithmic idea; they are not claims that every such system literally uses IDDFS.

💡 Common misconceptions

  • “DLS always finds the goal.” No. A limit below the goal depth can cause a cutoff.
  • “IDDFS never repeats nodes.” It intentionally repeats earlier shallow work in later iterations.
  • “IDDFS is just BFS.” No. It uses repeated depth-first searches with increasing limits.
  • “A bigger DLS limit is always better.” A larger limit can increase execution time; Reema Thareja explicitly notes this trade-off. fileciteturn23file12

🎓 Exam Corner

  • Define DLS. Depth-first search with a fixed depth limit; nodes at the limit are not expanded.
  • Explain IDDFS. Repeated DLS with gradually increasing depth limits until the goal is found.
  • State IDDFS complexity. The VTU material gives O(bd) time and O(b·d) space. fileciteturn23file6
  • Why is IDDFS useful? It combines DFS depth/memory efficiency with progressive, complete search when the goal depth is unknown, under the source's stated assumptions. fileciteturn23file0
  • Important comparison: DLS can fail with a poor cutoff; IDDFS avoids having to know the correct depth in advance by increasing it systematically.

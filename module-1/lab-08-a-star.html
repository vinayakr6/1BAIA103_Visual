⭐ Part A — A* Search

A* is an informed search algorithm. The supplied Reema Thareja material presents it as an informed search algorithm that combines the actual cost already travelled with an estimated cost to the goal. The evaluation function is:

f(n) = g(n) + h(n)

g(n)

Cost of the path from the start node to node n.

“What have I spent?”

h(n)

Heuristic estimate of the cost from n to a goal.

“How far might remain?”

f(n)

Combined evaluation used to decide which node is most promising.

“Estimated total”

The supplied Reema Thareja text lists A* under informed search and describes its evaluation function using g(n) and h(n). fileciteturn25file17

🪜 A* Step-by-Step

  1. Place the start node in the frontier/OPEN structure.
  2. Compute or obtain g(n), h(n), and therefore f(n).
  3. Select the most promising node according to the A* evaluation.
  4. Expand it and generate successors.
  5. Update path costs and priorities when a better route is discovered.
  6. Continue until the goal is selected/reached under the algorithm's termination conditions.
A* idea
OPEN  = nodes waiting to be explored
CLOSED = nodes already explored

🧠 Part B — Knowledge Representation (KR)

Knowledge Representation and Reasoning (KR/KRR) is concerned with representing knowledge so that an AI agent can use it for reasoning and intelligent behaviour. Reema Thareja emphasises that KR is more than simply storing data: it represents information such as beliefs, intentions, judgments and facts in a form an intelligent system can use. fileciteturn25file14

Real World
→
Represent Knowledge
→
Reason / Infer
→
Intelligent Action
Simple distinction: A database may store data. A knowledge representation system is designed so an AI system can represent and reason with knowledge.

📦 What knowledge needs to be represented?

Reema Thareja identifies several things that AI systems may need to represent:

Objects

Relevant entities and their facts, such as vehicles and roads for a self-driving car.

Events

Actions occurring in the real world, such as applying brakes when an obstacle appears.

Performance

Information about how actions are performed.

Meta-knowledge

Knowledge about knowledge — what the system knows.

Facts

Truths about the world that need to be available to an intelligent agent.

Knowledge Base

A collection of represented sentences/facts used by the knowledge-based agent.

These categories are explicitly described in the supplied Reema Thareja chapter. fileciteturn25file0

🤖 Knowledge-Based Agent (KBA)

A knowledge-based agent maintains knowledge about its environment and uses reasoning over that knowledge to decide what action to take. Reema Thareja identifies the knowledge base and inference engine as central components. fileciteturn25file4

Russell & Norvig likewise describe a knowledge-based agent as taking a percept, adding it to the KB using TELL, asking the KB what action to take using ASK, then telling the KB which action was performed. fileciteturn25file3

🔄 TELL → INFER → ASK → PERFORM

1. TELL

Add information to the knowledge base.

2. INFER

Derive new knowledge from existing knowledge using rules.

3. ASK

Query the knowledge base for what action or conclusion follows.

4. PERFORM

Execute the selected action.

Reema Thareja explicitly describes TELL, ASK and PERFORM operations and explains that the inference engine derives new sentences from old ones. fileciteturn25file1

🏗️ Requirements of a Good KR System

Representational Accuracy

Represent the kinds of knowledge required by the system.

Inferential Adequacy

Manipulate representations to produce new knowledge.

Inferential Efficiency

Guide reasoning toward useful results efficiently.

Acquisitional Efficiency

Make it easier to acquire new knowledge.

These four requirements are explicitly given in Reema Thareja's knowledge representation chapter. fileciteturn25file4

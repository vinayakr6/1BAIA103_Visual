Informed search adds problem-specific information about the goal. A heuristic function h(n) estimates how close a state is to the goal.

UNDERSTAND: Pure Heuristic Search

The supplied module material describes pure heuristic search as expanding nodes according to h(n), maintaining OPEN and CLOSED lists, and selecting the node with the lowest heuristic value.

OPEN = nodes waiting to be expanded CLOSED = nodes already expanded repeat: choose node with lowest h(n) move it to CLOSED expand its successors insert promising successors into OPEN until goal is found

Lower h(n) means the node appears closer to the goal.

Important limitation

Greedy best-first search chooses what appears best at the moment. The supplied reference notes that it is not an optimal algorithm and can behave poorly in some cases.

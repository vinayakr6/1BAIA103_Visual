🧭 From Blind Search to Informed Search

Uninformed algorithms such as BFS and DFS search without information about where the goal is. Informed search uses additional information about the search space—especially an estimate of how far a node is from the goal—to guide expansion. The VTU material describes it as a way to find a goal efficiently by using extra information about the search space. fileciteturn24file16

Key idea: Informed search is “guided” search. The guidance is supplied by a heuristic function rather than by blindly choosing the next node.

📏 The Heuristic Function h(n)

Russell & Norvig define the heuristic function as the estimated cost of the cheapest path from the state at node n to a goal state. In route finding, straight-line distance to the destination is a common example. fileciteturn24file11

h(n) = estimated cost from n → goal

Low h(n)

The node appears closer to the goal.

More promising

High h(n)

The node appears farther from the goal.

Less promising

Domain knowledge

A useful heuristic captures information about the problem domain.

Guidance

Reema Thareja describes the heuristic function as an estimate used to determine how close the agent is to the goal and notes that heuristic methods can reduce unnecessary exploration. fileciteturn24file0

🔎 1. Pure Heuristic Search

The supplied Reema Thareja text presents pure heuristic search as a simple heuristic-search approach that expands nodes based on their heuristic value h(n). It maintains two lists: OPEN for nodes not yet expanded and CLOSED for nodes already expanded. At each step, the node with the lowest heuristic value is selected. fileciteturn24file0

Algorithm idea

  1. Put the start node in OPEN.
  2. Choose the OPEN node with the smallest heuristic value.
  3. Move it to CLOSED.
  4. Expand it and calculate heuristic values for successors.
  5. Continue until the goal is reached or OPEN becomes empty.

🥇 2. Best-First Search (Greedy Search)

Reema Thareja describes Greedy Best-First Search as selecting the path that appears best at the moment, using the heuristic to choose the most promising node; it is implemented with a priority queue. fileciteturn24file14

Russell & Norvig express the same greedy principle with the evaluation function:

f(n) = h(n)

Thus, the smallest h(n) gets priority. The algorithm is “greedy” because it tries to get as close to the goal as possible at each step. fileciteturn24file12

Important: Greedy Best-First Search is not optimal. A node that looks closest according to h(n) can lead to a worse overall route. Reema Thareja also lists getting stuck in loops and non-optimality among its disadvantages. fileciteturn24file14

Russell & Norvig explain that informed search uses domain-specific hints about the location of goals to find solutions more efficiently than uninformed search. fileciteturn24file11

🚦 When should you use which?

Use uninformed search

When no useful domain heuristic is available.

Use heuristic search

When domain knowledge can estimate closeness to the goal.

Use Greedy Best-First

When reaching a promising goal quickly is more important than guaranteeing the lowest-cost solution.

⚠️ Common Misconceptions

  • “Heuristic means exact distance.” No. It is an estimate.
  • “Lowest h(n) always gives the shortest path.” No. Greedy search is not optimal. fileciteturn24file12
  • “Informed means the AI knows the answer.” No. It has useful guidance, not certainty.
  • “A heuristic is useful only for maps.” No. The idea is general; maps provide an intuitive example.

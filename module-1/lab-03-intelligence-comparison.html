AI, Augmented Intelligence, Cognitive Computing, Machine Learning & Deep Learning

These terms are related, but they are not interchangeable. This lesson builds a visual mental model for understanding what each term means, how the course resources distinguish them, and where Machine Learning and Deep Learning fit within Artificial Intelligence.

🤖 AI
Broad field of intelligent machine behaviour.
🤝 Augmented Intelligence
Weak AI that assists humans to improve tasks or decisions.
🧠 Cognitive Computing
Systems/products intended to mimic or augment human thought processes.
📊 ML → 🧬 DL
Learning from data, with DL using deep neural networks.
1 · Learning Objectives

By the end of this lab, you should be able to…

  • Explain how Artificial Intelligence, Augmented Intelligence and Cognitive Computing differ according to the supplied course resources.
  • Explain the course's description of AI in machines as simulating how humans sense, learn, process and react to information.
  • Define Machine Learning and explain how it uses data and patterns rather than manually written rules for every prediction.
  • Explain Deep Learning as an ML technique using neural networks with multiple layers.
  • Distinguish AI, ML and DL without treating them as synonyms.
  • Compare traditional programming with ML-oriented programming.
  • Choose the appropriate term when given a real-world scenario.

3 · Artificial Intelligence in Machines

What does “AI” mean in this context?

The Module 1 resource says that when AI is used in reference to machines, it makes machines obtain human intelligence by simulating how humans sense, learn, process and react to information in the environment. This does not mean a machine literally has a human brain; it describes the intended intelligent behaviour.

👁️SenseReceive information from the environment.
📥LearnUse data/experience where applicable.
🧠ProcessApply rules, algorithms or learned representations.
🎯DecideGenerate a prediction/decision.
⚡ReactProduce an output/action.
4 · Augmented Intelligence

AI that assists the human

The supplied Module 1 handout describes augmented intelligence as a type of weak AI that assists humans to improve tasks or decisions. The textbook similarly describes augmented intelligence as weak AI that improves products and services, giving the example of automatically highlighting important information in a report.

👩‍💼

Human

Defines the goal, interprets the situation and remains the decision-maker in the example.

🤖

AI assistance

Finds/highlights useful information and reduces the effort needed to inspect a large report.

🤝

Combined outcome

The machine supports the human rather than being presented as a replacement for the human.

Course definition: Augmented intelligence is presented as weak AI that assists humans to improve tasks or decisions. fileciteturn18file1
5 · Cognitive Computing

Mimicking and augmenting human thought processes

The Module 1 handout describes cognitive computing as systems or products that mimic human thought processes to enhance decision-making. Reema Thareja describes the term as being coined for products and services that mimic or augment human thought processes. In the later AI-technologies material, cognitive computing is described as a subfield of AI intended to support natural, human-like interaction by analysing text, speech, images or objects.

📄TextRead/analyse textual information.
🎙️SpeechProcess spoken information.
🖼️ImagesAnalyse visual information.
🧠InterpretCombine information.
💡Decision supportProduce a useful response.
Important distinction: Cognitive computing focuses on a human-like interaction/thought-process orientation; it should not be treated as a synonym for all AI.

7 · Machine Learning

Teaching machines from data and experience

Reema Thareja describes Machine Learning as a branch of computer science that analyses data and identifies patterns to teach a machine to deduce results and make decisions. ML algorithms learn from experience rather than instructions; they analyse datasets, compare outputs and can repeat the learning process when errors occur so that accuracy improves.

🗃️DataHistorical examples or observations.
🔎PatternsAlgorithm identifies useful relationships.
🧠ModelLearned representation of those relationships.
🎯PredictionApply model to new input.
🔁ImproveUse errors/evaluation to improve the model.
8 · A Human Learning Analogy

The “10, 20, 30, 40, ?” example

The textbook asks you to find the missing number in 10, 20, 30, 40, ?. A person notices the pattern and answers 50. The text uses this to introduce the central idea of ML: making machines learn patterns from data.

Input

10, 20, 30, 40

Observed pattern

Each value increases by 10.

Learned rule

Next value = previous value + 10.

Prediction

50

This is an intuition-building analogy, not a claim that a real ML model always learns a simple explicit rule.

9 · Traditional Programming vs ML

Where does the “program” come from?

👨‍💻 Traditional programming

Data + manually written rules → output

The programmer formulates/codes the rules and the program applies them to input data.

VS

📊 Machine learning

Data + observed output → learned model → prediction

The algorithm uses examples to formulate patterns/rules represented in a predictive model.

The textbook's customer-churn example uses customer demographics and transactions as historical inputs and historical churn outcomes as outputs; the ML algorithm uses these to formulate a predictive model for future churn. fileciteturn18file0
10 · Case Study

Finding one person's photos

The textbook gives a case study: filtering one person's photos from 100 images is difficult to solve reliably using traditional programming rules or pixel-by-pixel comparison. With ML, multiple photos can be supplied as examples so that a model can learn visual characteristics of that person.

🖼️Example photosMany images of the person.
🔎Learn patternsModel learns useful visual features.
🧠ModelRepresents learned patterns.
📷New imageUnknown photo arrives.
✅ClassifyPredict whether it matches.
11 · Deep Learning

Machine Learning with deep neural networks

The course material describes Deep Learning as a powerful technique within ML that uses neural networks with many layers to process and learn from data, especially complex patterns in large datasets. Reema Thareja describes deep learning as an ML technique using neural networks with several processing layers to classify, infer and predict outcomes.

1️⃣
Input layer

Receives raw data.

2️⃣
Hidden layers

Successive layers process and learn representations.

3️⃣
Output layer

Produces the final prediction/classification.

🔁
Training

Forward propagation produces output; backward propagation updates weights based on error.

12 · Visual Example — Image Recognition

How a deep network can build representations

🖼️Raw imagePixels enter the network.
📐Early featuresEdges/simple patterns.
🔷Intermediate featuresShapes and parts.
👁️Higher featuresEyes, nose, mouth or object parts.
🎯OutputClass/prediction.

The course material uses this style of example: in image recognition, early layers can detect edges, later layers can recognize shapes and further layers can identify objects. The advantage emphasized is automatic feature extraction from raw data.

ML vs DL intuition: conventional ML may require relevant features to be manually extracted; deep learning can automatically learn representations/features from raw data through multiple layers. fileciteturn18file7
13 · Deep Learning Training

Forward propagation → error → backward propagation

📥InputRaw data enters.
➡️ForwardInformation passes through layers.
🎯OutputPrediction is generated.
📏ErrorPrediction is compared with target.
⬅️BackwardWeights are updated to reduce error.

The supplied Module 3 material explains forward propagation as movement of computations toward the output layer and backward propagation as sending error information backward to adjust weights. This training cycle is repeated to improve accuracy. fileciteturn18file14

16 · Common Misconceptions
“AI, ML and DL are three names for exactly the same thing.”

No. The course presents ML as a branch/application of AI and DL as an ML technique using deep neural networks.

“Augmented intelligence means stronger-than-human AI.”

No. In the supplied course material, augmented intelligence is described as weak AI that assists humans to improve tasks or decisions.

“Cognitive computing is a replacement for AI.”

No. The resource describes cognitive computing in relation to AI and human-like thought processes/interaction.

“Machine learning means no human involvement at all.”

The textbook says ML algorithms learn from experience rather than explicit instructions for each output, but people still define the problem, collect/select data, choose methods and evaluate systems.

“Deep learning automatically means the model is correct.”

No. Deep learning requires training and evaluation; the course explicitly describes error calculation and weight updates during training.

19 · Takeaways
  • AI is the broad concept of making machines perform tasks associated with intelligence.
  • Augmented Intelligence, in this course, is weak AI that assists humans to improve tasks or decisions.
  • Cognitive Computing focuses on mimicking/augmenting human thought processes and human-like interaction.
  • Machine Learning learns patterns from data/experience rather than requiring every rule to be explicitly written.
  • Deep Learning is an ML technique based on neural networks with multiple layers.
  • Traditional programming and ML are complementary; ML does not simply replace conventional programming.
  • Always distinguish the conceptual relationship among these terms from the particular technology used in a real application.

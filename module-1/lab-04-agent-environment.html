MODULE 1 · LAB 04 · CO1

Agent & Environment

Artificial Intelligence can be understood through the idea of an agent: something that perceives its environment through sensors and acts on that environment through actuators/effectors. Learn how percepts, actions, rationality and PEAS fit together, then experiment with a simple agent.

👁️ Perceive
Sensors receive percepts from the environment.
🧠 Decide
The agent uses its program/knowledge to choose an action.
🦾 Act
Actuators/effectors change or interact with the environment.
🎯 Be rational
Choose actions intended to maximize the performance measure.
1 · Learning Objectives

By the end of this lab, you should be able to…

  • Explain the agent–environment interaction loop.
  • Differentiate human, robotic and software agents using the supplied examples.
  • Explain performance measure, agent behaviour and agent function.
  • Explain rationality using performance measure, percept sequence, prior knowledge and available actions.
  • Construct a PEAS description for a simple AI task.
  • Explain the basic structure Agent = Architecture + Agent Program.
  • Recognize the main environment properties introduced in the course: observable, deterministic, episodic/sequential, static/dynamic, discrete/continuous, single/multi-agent and known/unknown.

Human, Robotic and Software Agents

🧑

Sensors: eyes, ears, nose, tongue and skin.

Effectors: hands, legs and mouth for taking actions.

6 · Rationality

What makes an agent rational?

Rationality means selecting an action expected to maximize the agent's performance measure given the evidence in its percept sequence and its built-in/prior knowledge. Russell & Norvig identifies four factors: performance measure, prior knowledge, possible actions and percept sequence to date. fileciteturn19file2

🎯Performance measure
How success is judged
📚Prior knowledge
What the agent already knows
🦾Possible actions
What it can do
👁️Percept sequence
What it has observed
Rational ≠ omniscient. A rational agent acts appropriately based on available evidence; it does not need to know the actual future outcome. The supplied Russell & Norvig text explicitly distinguishes rationality from omniscience. fileciteturn19file2
7 · The Vacuum-Cleaner Example

A classic way to understand rational agents

Environment

Two locations/squares, with dirt possibly present.

Percept

Current location and whether it contains dirt.

Actions

Left, Right, Suck.

Performance

Reward clean squares over time, with the exact measure depending on the task.

The important lesson is that whether the vacuum agent is rational depends on the performance measure and assumptions about the environment. Russell & Norvig shows that an agent can be rational under one performance measure and irrational under another. fileciteturn19file7

9 · Structure of an Intelligent Agent

Agent = Architecture + Agent Program

🖥️🤖
Architecture

The machinery/platform on which the agent operates — for example, a computer, robot, vehicle and its sensors/actuators.

+
💻

The implementation that processes percepts and selects actions.

Russell & Norvig states that the agent program implements the agent function, while the architecture is the computing device with physical sensors and actuators. fileciteturn19file3

10 · Environment Properties

The environment changes the agent design

👁️ Fully vs Partially Observable

Fully observable: sensors provide the complete relevant state.

Partially observable: the agent cannot perceive everything relevant.

Example in the course: chess is observable; Kriegspiel chess is partially observable. fileciteturn19file5

🎲 Deterministic vs Non-deterministic

Deterministic: next state can be determined from the current state/action.

Non-deterministic: outcomes involve uncertainty.

Course examples: chess vs ludo/dice roll. fileciteturn19file13

🕰️ Static vs Dynamic

Static: environment does not change while the agent is acting.

Dynamic: environment changes during action.

Semi-dynamic: environment does not change but performance can change.

🔢 Discrete vs Continuous

Discrete: limited/well-defined states.

Continuous: no such limitation on percepts/actions.

Course examples: chess vs self-driving car. fileciteturn19file12

👤 Single vs Multi-agent

Single: one agent.

Multiple: two or more agents, potentially cooperative or competitive.

Course examples: vacuum cleaner vs chess/taxi driving. fileciteturn19file13

📚 Known vs Unknown

Known: the agent knows the results of actions.

Unknown: the agent must learn how to act.

The handout gives reinforcement learning as an example of learning in an unknown environment. fileciteturn19file12

🔄 Episodic vs Non-episodic

Episodic: each episode is independent.

Non-episodic: current actions affect future decisions.

Course example: long-term decision making is non-episodic. fileciteturn19file13

🔓 Accessible vs Inaccessible

Accessible: agent has full access to environment information.

Inaccessible: complete information is unavailable.

This terminology appears in the supplied Module 1 handout. fileciteturn19file13

12 · Types of Agents

Agent programs introduced in the course

1. Simple Reflex Agent

Chooses actions based only on the current percept. The course notes that its environment is completely observable in the basic treatment.

2. Model-Based Reflex Agent

Maintains an internal state to represent aspects of the current situation that are not directly observable. It considers how the world evolves and how its actions affect the world. fileciteturn19file16

3. Goal-Based Agent

Uses goals to select actions that lead toward desired states. It is useful when an agent must consider future consequences.

4. Utility-Based Agent

Uses a utility measure to compare possible outcomes and select actions that maximize expected utility under uncertainty. fileciteturn19file4

5. Learning Agent

Learns from past experiences and adapts. The handout identifies four components: learning element, critic, performance element and problem generator. fileciteturn19file15

16 · Common Misconceptions
“An agent is only a physical robot.”

No. The supplied sources explicitly include humans and software agents.

“Sensors and actuators are the same.”

No. Sensors provide perceptual input; actuators/effectors are used to perform actions.

“A rational agent always gets the best possible outcome.”

Rationality is based on available evidence, prior knowledge, available actions and the performance measure. It is not omniscience. fileciteturn19file2

“PEAS is an AI algorithm.”

PEAS is a framework for describing the task environment: Performance measure, Environment, Actuators and Sensors.

“Every environment is fully observable and deterministic.”

No. The course explicitly introduces partially observable and non-deterministic environments and several other dimensions.

18 · Takeaways
  • An agent perceives an environment and acts on it.
  • Sensors provide percepts; actuators/effectors perform actions.
  • An agent function maps percept sequences to actions.
  • A rational agent chooses an action expected to maximize its performance measure given available evidence and knowledge.
  • PEAS helps specify the task environment before designing the agent.
  • Agent = Architecture + Agent Program.
  • Environment properties strongly influence appropriate agent design.
  • Learning agents contain a learning element, critic, performance element and problem generator in the course's framework.

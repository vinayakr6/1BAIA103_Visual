An intelligent agent perceives its environment through sensors and acts on it through actuators. The agent function maps percept information to an action.

Percept history
→
Agent function / program
→
Action

Performance measure
Rational agent: chooses an action expected to maximise performance given the available percepts, knowledge and constraints.

INTERACT: Agent types

Simple Reflex

Acts from current percept using condition–action rules.

Model-Based

Maintains an internal state/model to handle partially observable situations.

Goal-Based

Chooses actions that help achieve explicit goals.

Utility-Based

Uses preferences or utility to compare desirable outcomes.

Learning Agent

Improves performance through experience and feedback.

APPLY: Environment properties

PropertyQuestion to ask
ObservableCan the agent perceive the complete relevant state?
DeterministicDoes an action have a predictable outcome?
